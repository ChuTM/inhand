A macOS tool for teachers — watch student screens, share your own, push focus wallpapers, run approved commands. All over the school's own network. Open source.

Get started View on GitHub

The teacher's view

One window. Every student.

The admin console lists every device that has joined today — online status, screen thumbnails, one-click sharing and focus controls.

What it does

Everything a classroom needs, on the LAN

Screen viewing & sharing

Watch live student screens and broadcast your own, over the LAN. Classroom content never touches the cloud.

Focus wallpapers

Lock every student Mac onto one image in one click, release it when the lesson moves on.

Approved commands

Whitelisted commands run only with the teacher's explicit decision. Keys stay on the Mac.
