# Docs

Tutorials for teachers and students using the InHand classroom management software.

## Getting started

- [Installing the Student Client](student-install.md) — install, authorise and update the student client on every student Mac. Uses the official installation service at [ihinstall.web.app](https://ihinstall.web.app/).
- [Teacher Setup Guide](teacher-setup.md) — sign in, create registration tokens, register your school and grant screen-sharing access.
- [Classroom Guide](classroom-guide.md) — a practical walkthrough of sharing, focus mode and session control during a lesson.
- [How we protect your data](data-security.md) — encryption, access control and what stays on the school network.
