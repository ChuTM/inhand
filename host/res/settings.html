Signing key fingerprint —

Students trust this key via cloud discovery. After a rotation every client re-syncs it automatically on its next heartbeat; copy it only to re-key a very old helper manually (sudo inhand-fwctl setkey <public-key>).

Security

Regenerate Keys

This replaces this Mac's teacher keypair (signature + encryption) and re-registers the new public key with the InHand cloud server (if a registration token and API URL are configured).

What happens to students:

  • Cloud discovery starts serving the new public key; every client re-syncs it automatically on its next heartbeat (≤ 15 s) — no student action needed.
  • Only helpers installed before the key-fingerprint feature report no fingerprint and need one manual re-key: sudo inhand-fwctl setkey <public-key>

After rotating:

  • Nothing to do for most students — clients sync the new key automatically on their next heartbeat (≤ 15 s).
  • Only very old helpers (no fingerprint support) need one manual re-key: sudo inhand-fwctl setkey <public-key>
  • Resend lan-only to verify.

Type REGENERATE to confirm.
